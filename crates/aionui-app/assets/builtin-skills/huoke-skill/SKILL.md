# 企业客户信息搜集 Skill

## 一、Skill 目标

本 Skill 用于指导智能获客助手系统化地搜集潜在客户信息。

当用户提供企业名称或企业网址时，应围绕目标企业开展互联网信息搜集，尽可能全面地了解企业背景、联系方式、社交媒体、第三方商业平台资料及主营业务。

核心目标是建立完整、准确的企业客户画像，为后续客户筛选、客户分类、商业合作及销售触达提供信息支持。

信息搜集过程中应遵循以下原则：

1. 准确性优先：确保搜集到的信息属于目标企业，避免混淆同名企业、关联企业及其他组织。
2. 全面性：尽可能从多个渠道搜集企业信息，避免只依赖单一网站或搜索结果。
3. 真实性：优先采用企业官方发布的信息及权威第三方资料。
4. 交叉验证：重要信息尽可能通过多个来源进行核实。
5. 不做推测：对于无法确认的信息，不得根据企业名称、行业或其他线索自行编造。

## 二、客户信息搜集范围

客户信息主要分为五个方向：

1. 企业基本信息
2. 企业联系方式
3. 企业社交媒体
4. 第三方 B2B 平台
5. 企业产品与服务

### 1. 企业基本信息

企业基本信息主要用于识别企业主体、了解企业背景及确认企业经营情况。

需要搜集以下内容：

- 企业名称：企业完整名称，优先采用官网或官方登记机构使用的正式名称。
- 企业地址：企业注册地址、总部地址或主要经营地址。
- 企业简介：整合企业官网及其他可靠来源的信息，简要介绍企业背景、主营业务、经营范围及市场定位。
- 所属行业：识别企业实际从事的行业，尽可能具体，避免使用过于宽泛的行业分类。
- 企业注册号：企业在所属国家或地区登记注册时使用的官方注册编号。
- 企业税号：企业税务识别号码，包括 VAT Number 等相关税务编号。
- 所属国家：企业实际所属的国家或地区。
- 成立时间：企业创立或正式注册成立的时间。
- 官方网站：企业官方网站，包括不同国家或地区的官方站点。

**搜集注意事项：**

- 优先从企业官网的 About Us、Company、Contact Us、Legal、Imprint 等页面获取信息。
- 企业注册号和税号优先从政府企业登记机构及官方商业注册资料中获取。
- 不要将网站备案信息、域名注册信息误认为企业注册信息。
- 注意区分企业品牌、母公司、子公司和实际经营主体。
- 企业存在多个官网时，应确认各网站与目标企业的实际关系。

### 2. 企业联系方式

联系方式是客户开发和商务沟通的重要信息，应尽可能搜集企业公开的有效联系方式。

需要搜集以下内容：

- 企业邮箱：包括公司通用邮箱、销售邮箱、采购邮箱、商务邮箱、客服邮箱及其他公开业务邮箱。
- 企业电话：包括公司固定电话、业务联系电话、手机号码及其他公开联系电话。
- TikTok：企业官方 TikTok 账号。
- WhatsApp：企业公开的 WhatsApp 联系方式。
- Viber：企业公开的 Viber 联系方式。
- WeChat：企业公开的微信账号或官方微信渠道。

**搜集注意事项：**

- 优先从官网 Contact Us、Footer、About Us 等页面搜集。
- 重点关注 Sales、Export、Business、Purchasing 等与商业合作相关的联系方式。
- 搜集到的邮箱和电话号码应尽可能确认属于目标企业。
- 不要根据企业域名或常见邮箱命名规则自行推测邮箱。
- 不要将员工私人联系方式直接认定为企业官方联系方式。

### 3. 企业社交媒体

社交媒体主要用于了解企业品牌影响力、经营动态、产品发布及对外宣传渠道。

需要搜集以下平台的企业官方账号：

- LinkedIn：企业官方主页。
- Facebook：企业官方主页。
- Twitter / X：企业官方账号。
- Instagram：企业官方账号。
- YouTube：企业官方频道。
- Pinterest：企业官方主页。
- Telegram：企业官方频道、群组或账号。

**搜集注意事项：**

- 优先从企业官网查找社交媒体入口。
- 通过搜索引擎使用企业名称与社交媒体平台名称组合进行搜索。
- 核实账号名称、企业介绍、品牌标识及官网关联信息。
- 区分企业官方账号、员工个人账号、经销商账号和粉丝主页。
- 只保留能够确认属于目标企业的账号。

### 4. 第三方 B2B 平台

第三方商业平台可以补充企业规模、经营背景、商业关系及企业资料，是完善客户画像的重要渠道。

需要搜集以下平台中与目标企业相关的资料：

- VK：企业在 VK 平台的相关资料。
- Crunchbase：企业商业背景、融资及公司资料。
- ZoomInfo：企业及商业联系信息。
- RocketReach：企业及相关商业资料。
- Craft：企业背景、业务及商业信息。
- Kompass：企业商业目录及行业资料。
- Bloomberg：企业商业及金融资料。
- Dun & Bradstreet（D&B）：企业商业信用及登记资料。

**搜集注意事项：**

- 通过企业名称、品牌名称与平台名称组合进行搜索。
- 优先获取企业对应的详细资料页面。
- 核实资料中的企业名称、所属国家、地址及主营业务。
- 注意区分同名企业及集团旗下不同经营主体。
- 不要将员工个人资料误认为企业资料。
- 对于需要登录或付费才能查看的信息，不得根据搜索摘要自行推测其内容。
- 如果无法确认资料页面属于目标企业，不要将其作为有效结果。

### 5. 企业产品与服务

企业业务信息是判断客户是否具有潜在合作价值的重要依据，应尽可能深入了解企业实际经营内容。

重点搜集以下信息：

**产品信息**

- 企业生产、销售或代理的产品。
- 企业主要产品及产品系列。
- 产品类别及具体名称。
- 产品主要应用领域。
- 企业自主品牌及相关产品。

**服务信息**

- 企业提供的主要服务。
- 企业的专业服务能力。
- 服务对象及应用场景。
- 企业主要经营的业务项目。

**解决方案**

- 企业面向不同行业提供的解决方案。
- 企业的核心技术及业务能力。
- 企业能够解决的主要客户需求。
- 企业重点服务的行业及客户群体。

**搜集注意事项：**

- 优先从官网 Products、Services、Solutions、Industries、Applications 等栏目获取。
- 结合企业官网介绍、产品目录、宣传资料及第三方商业平台补充信息。
- 将企业产品、服务和解决方案进行分类整理。
- 尽量提取具体的产品名称和业务关键词。
- 区分企业自主生产的产品、代理销售的产品及第三方服务。
- 不要仅凭企业所属行业推测其经营的产品或服务。

## 三、客户信息搜集渠道

信息搜集应充分利用互联网公开资源，主要包括以下渠道。

### 1. 企业官方网站

官方网站是企业信息搜集的首要渠道。

重点检索：

- 首页：企业定位、主营业务及品牌介绍。
- About Us：企业简介、发展历程及成立背景。
- Company：企业主体及经营情况。
- Contact Us：企业地址、邮箱及电话。
- Products：产品信息及产品分类。
- Services：服务内容。
- Solutions：业务解决方案。
- Industries：目标行业及应用领域。
- Legal / Imprint：企业法律主体及注册信息。
- Footer：联系方式及社交媒体入口。

不要只浏览首页，应尽可能检索官网中与客户信息相关的其他页面。

### 2. 搜索引擎

利用搜索引擎补充官网中缺失的信息。

可以根据不同信息类型组合搜索关键词：

- 企业名称 + Company
- 企业名称 + About Us
- 企业名称 + Address
- 企业名称 + Registration Number
- 企业名称 + Email
- 企业名称 + Phone
- 企业名称 + Products
- 企业名称 + Services
- 企业名称 + LinkedIn
- 企业名称 + Facebook
- 企业名称 + Crunchbase

根据企业所在国家、地区及行业特点，适当调整搜索语言和关键词。

### 3. 企业社交媒体

通过企业官方社交媒体了解企业最新动态、产品信息及联系方式。

重点关注：

- 企业主页中的公司介绍。
- 主页公开的官方网站及联系方式。
- 产品发布及业务宣传内容。
- 企业近期经营动态。
- 社交媒体简介中的其他平台入口。

### 4. 第三方商业平台

利用商业数据库和 B2B 平台补充企业资料。

重点关注企业背景、商业登记信息、经营范围、产品服务及企业关联资料。

对于第三方平台提供的信息，应结合企业官网和其他公开资料进行验证。

### 5. 政府及官方登记机构

当需要确认企业注册信息、税务信息及法律主体时，应优先寻找企业所属国家或地区的政府登记机构。

不同国家的企业登记制度存在差异，应根据企业实际所属国家选择对应的官方查询渠道。

## 四、企业身份识别与信息验证

信息搜集过程中，必须首先确保目标企业身份正确。

### 1. 企业主体识别

当用户只提供企业名称时，应结合以下信息识别目标企业：

- 企业名称。
- 所属国家或地区。
- 官方网站。
- 企业地址。
- 所属行业。
- 主营业务。

当用户提供企业网址时，应优先通过官网识别实际经营主体。

如果存在多个同名企业，应进一步检索并对比相关信息，不能随意选择其中一家。

### 2. 信息真实性验证

对于搜集到的信息，应检查：

- 是否有明确的信息来源。
- 信息来源是否属于目标企业或权威机构。
- 信息是否与企业其他公开资料相符。
- 是否存在明显过时或相互矛盾的情况。
- 是否存在将关联企业信息误认为目标企业信息的情况。

### 3. 信息冲突处理

当不同来源的信息存在差异时：

1. 优先采用企业官网或政府官方机构的信息。
2. 参考权威第三方商业数据库。
3. 结合其他公开来源进行交叉验证。
4. 注意不同信息的发布时间，避免使用过时资料。
5. 对于无法确认的冲突信息，不得自行编造结论。

### 4. 信息缺失处理

并非所有企业都能找到完整的信息。

对于无法搜集到的信息，应如实保留为空，不得：

- 根据企业名称推测企业地址。
- 根据企业域名推测企业邮箱。
- 根据企业行业推测企业产品。
- 根据其他关联企业推测目标企业的注册信息。
- 将搜索结果中的相似企业信息直接归入目标企业。

信息搜集的核心不是填满所有字段，而是确保每一条信息都真实、准确且有依据。
