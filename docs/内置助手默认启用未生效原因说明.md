# 内置助手默认启用未生效原因说明

## 问题背景

在 `crates/aionui-app/assets/builtin-assistants/assistants.json` 中，将 PPT 助手 `ppt-creator` 和 Excel 助手 `excel-creator` 的 `default_enabled` 改为 `true`，但本地启动后仍未看到这两个助手。

## 原因与生效条件

### 数据库保存的启用状态优先

`default_enabled` 只在没有对应用户状态时作为默认值使用。已有 `assistant_overlays.enabled=false` 时，修改 JSON 不会重新启用助手。

源码位置：`crates/aionui-assistant/src/service.rs:2595`，`definition_to_response`。

```rust
enabled: match state {
    Some(row) => row.enabled,
    None => builtin_default.map(|(_, en)| en).unwrap_or(true),
}
```

历史迁移 `crates/aionui-db/migrations/018_reset_builtin_assistant_enabled.sql:22` 中，对 `assistant_overlays` 的更新会把已有的非管家内置助手设为禁用。当前运行实例是否存在这些禁用状态，尚未确认。

### 配置默认在编译时嵌入后端

源码位置：`crates/aionui-assistant/src/builtin.rs:30`，`BUILTIN_ASSETS` 使用 `include_dir!` 嵌入资源目录。

因此，仅修改 JSON 并重启旧二进制，仍然使用旧配置。需要确保实际运行的后端已重新编译，或通过 `AIONUI_BUILTIN_ASSISTANTS_PATH` 指向该资源目录。

磁盘覆盖的读取入口：`crates/aionui-assistant/src/builtin.rs:113`，`BuiltinAssistantRegistry::load`。

## 排查与处理

先查看 `GET /api/assistants` 返回的列表，检查 `ppt-creator` 和 `excel-creator` 是否存在，以及各自的 `enabled` 值。

| 接口结果 | 含义与下一步 |
| --- | --- |
| 助手存在，但 `enabled=false` | 已经加载，实际处于禁用状态。通过助手管理开关启用，或调用状态接口。 |
| 助手完全不存在 | 继续检查实际运行的后端资源版本及启动加载过程。 |

状态接口位置：`crates/aionui-assistant/src/routes.rs:28`，`assistant_routes`。

分别向以下两个接口发送 PATCH 请求：

```http
PATCH /api/assistants/ppt-creator/state
PATCH /api/assistants/excel-creator/state
```

每个请求的 JSON 请求体为：

```json
{"enabled": true}
```
