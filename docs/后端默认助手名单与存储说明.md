# 后端默认助手名单与存储说明

## 问题背景

用户问题：帮我看一下后端默认存储的助手有哪些。

## 结论

AionCore 后端默认内置并入库的助手共有 **21 个**，其中只有 **「AionUi管家」默认启用**，其余 **20 个默认关闭，但仍会存储**。

## 存储逻辑

- 启动初始化会遍历全部内置助手，写入 `assistant_definitions` 表，标记为 `source = "builtin"`、`owner_type = "system"`。入口：`crates/aionui-assistant/src/service.rs:251`（[查看源码](../crates/aionui-assistant/src/service.rs#L251)）。
- “是否启用”与“是否入库”分开处理；用户设置过启用状态后，以用户设置为准。见 `crates/aionui-assistant/src/service.rs:2666`（[查看源码](../crates/aionui-assistant/src/service.rs#L2666)）。

## 确认范围

本文记录的是**源码默认名单**，没有查询当前运行的数据库。


**Claude Code 助手默认是在后端启用的，不是在 `GuidPage.tsx` 中开启。** 这里有两个不同的开关：

### 1. Claude Code 运行时默认启用
`AionCore/crates/aionui-db/migrations/001_initial_schema.sql:192`

这里注册了名为 `Claude Code` 的 Agent，ID 为 `2d23ff1c`，初始 `enabled` 值为 `1`。

### 2. 自动生成的助手默认启用
**关键位置：`AionCore/crates/aionui-assistant/src/service.rs:708`**

后端会为符合条件的 Agent 自动生成助手：Agent 已启用、已安装、支持新增会话，且状态为 `Online` 或 `Unchecked`。首次创建助手状态时写入：

```rust
enabled: true,
```

生成逻辑位于 `AionCore/crates/aionui-assistant/src/service.rs:590`。**这个默认值适用于所有自动生成的助手，不仅是 Claude Code。**

### 如何关闭显示
在“助手”管理页 `/assistants` 中关闭 Claude Code 的启用开关即可；前端保存逻辑在：

`AionUi/packages/desktop/src/renderer/hooks/assistant/useAssistantEditor.ts:590`

它调用 `assistants.setState` 更新助手的 `enabled` 状态。**仅修改后端的默认值不会改变已经创建的助手状态；之前隐藏 Agents 设置页，也不会关闭这个助手。**
