# 命令行助手定义位置说明

## 问题背景

原问题：Aion CLI这个助手是在哪里定义的？

## 结论

`Aion CLI` 定义在 **AionCore 后端的内置 Agent 数据库初始化配置**中，界面里的助手由它自动生成。

## 代码位置

### 名称和配置

位置：`crates/aionui-db/migrations/001_initial_schema.sql:346`。

这里定义了名称 `Aion CLI`、Agent ID `632f31d2`、类型 `aionrs`、来源 `internal`，写入 `agent_metadata` 表。

### 助手生成逻辑

位置：`crates/aionui-assistant/src/service.rs:592`，符号：`reconcile_generated_assistant()`。

该方法根据 Agent 生成助手，默认助手 ID 为 `bare:632f31d2`，名称继承 Agent 的 `name`。

### 类型显示名

位置：`crates/aionui-common/src/enums.rs:40`。

映射为 `AgentType::Aionrs => "Aion CLI"`。

## 定位建议

找这个助手的原始定义，先看 SQL 第 346 行；找它如何进入助手列表，看 `reconcile_generated_assistant()`。
